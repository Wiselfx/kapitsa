Structured output 1/3: a grammar engine for JSON Schema and Qwen tool calls, with token masks (6.0 us mean, p99 39 us over Qwen's 248K-token vocabulary; equal to brute force at 5,471 states)

src/engine/grammar.{h,cpp}, no new dependency: a JSON Schema subset (types and type lists, properties, required,
additionalProperties, enum, const, items and prefixItems with minItems/maxItems, anyOf/oneOf, allOf merged, local
$ref with recursion, nullable, string minLength/maxLength, integer bounds), any JSON object, and Qwen's XML tool calls
(<tool_call> and </tool_call> as tokens; required, named, strict tools) compile into value nodes that a byte-level
pushdown matcher walks. Unsatisfiable slots are closed at compile time and keys that can only become a name already
written are given up at once, so a live state always allows some token. Bounded whitespace (48 bytes, 2 line breaks
between JSON tokens) and digit counts keep a model from running in place.

Masks: the vocabulary's bytes in a preorder trie, walked through the matcher's state and pruned at the first byte that
cannot follow. Free-text positions (a JSON string's content, a raw tool argument, a free parameter name, text before a
call) allow nearly every token: there the tokens that stay inside the text are a set precomputed per lexical state
(TokenTable's cache, with per-length bitmasks for limited strings), and only those that leave it are walked.

tools/grammar_test: schemas against accepted, open and rejected texts, schemas refused, tool-call grammars; with a
tokenizer (the 4B's), every mask along valid replies and random walks against brute force, and the mask time.

Measured (MacBook Pro M4 Pro, macOS 27.0.1, Qwen3.5 4B's tokenizer, warm, one core): mask time mean 6.0 us, median
2.5, p90 15.0, p99 39.0, max 157 over 5,471 states; 308 checks pass, also under ASan and UBSan (--quick: 614 states
against brute force).
